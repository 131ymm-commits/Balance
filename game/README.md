# game/ — играбельный слой (прототипы)

Ранние играбельные прототипы «второго билда» из [../docs/GAME.md](../docs/GAME.md) — рекрутинг/визия, **не доказательства** (доказательства — в `../stand/` и `../predictor/`). Однофайловые React-компоненты, создавались как артефакты claude.ai.

| Файл | Что это | Как запустить |
|---|---|---|
| `BalanceFuture.jsx` | проекция будущего с ползунком «насколько трудно обманывать» (зоны нарисованы вручную — иллюстрация, не расчёт) | любой React-плейграунд / вставить как артефакт |
| `BalanceMap.jsx` | территориальный слой антимонополии (Остром-8): власть дробится с ростом игроков; мок поверх картографии | любой React-плейграунд |
| `BalanceUniverse.jsx` | стратегическая игра, где «Вселенную» играет LLM через Anthropic API | **только** в среде артефактов claude.ai (там API-прокси без ключа) или с собственным ключом и правкой fetch |

По дизайну GAME.md §7 играбельная сборка обязана иметь режим худшего случая и ссылку на фазовые диаграммы стенда — в этих прототипах это ещё не реализовано (см. дорожную заметку в GAME.md).

## Художественный слой

**Верхний этаж: [`UNIVERSE_bible.md`](UNIVERSE_bible.md) — «Вселенная Баланса», библия франшизы.** Марвел-архитектура без центра: фазы, тайтлы, кроссоверы, мультиверс веток — плюс открытость SCP-модели. Ключевой закон: **канон — это механика, а не сюжет** (чек-лист каноничности из 8 пунктов, открытый процесс, форк вселенной легитимен). Комикс-стратегия: почему медиум идеален (вероятность как плашка в панели, гаттер как переход между ветками, производство без центра, путь Марвела комикс→экран). Кроссовер-события: «Точка ветвления» (= антология), «Сломанные ветки» (What-If-хоррор = институционализированный worst case), «Четвёртая ветка» (пост-титровая сцена всей франшизы — реальный запуск).

**Зонт: [`SERIES_balance_vetki_antologia.md`](SERIES_balance_vetki_antologia.md) — «БАЛАНС. Ветки», антология трёх реальностей.** Мастер-сценарий, сплетающий три мира в один сериал-мозаику: каждая серия = один принцип системы, показанный сразу в трёх ветках (прошлое / победившая вселенная / наш запуск). Рамка — симулятор ветвлений из GAME.md §5; грамматика переходов через предметы-рифмы; 10 серий-принципов; сезонная загадка точки ветвления. Понимание системы складывается триангуляцией.

Три ветки (самостоятельные библии):

[`STORY_kak_pal_kapitalizm.md`](STORY_kak_pal_kapitalizm.md) — **ветка А, «Хроника»**: рассказ «Как пал капитализм. И почему этого никто не заметил» + посерийная сетка. Ретроспектива из 2041-го: как система победила медленно и незаметно.

[`SERIES_balance_mir_kotoryj_schitaet.md`](SERIES_balance_mir_kotoryj_schitaet.md) — **ветка Б, «Мир, который считает»**: планетарный процедурал изнутри победившей вселенной. Земля-2, такт 48 часов, власть присутствия, личная земля, Вселенная и Флюгер.

[`SERIES_alt_nasha_realnost.md`](SERIES_alt_nasha_realnost.md) — **ветка В, «Альт»**: наша реальность, год запуска. Вторая смета города, вопрос с приложенной вероятностью, право первого ответа, лестница объяснений, обещание с интервалом.

**Комиксы (Фаза I, нулевой пакет):**

[`COMIC_flyuger_strips_0.md`](COMIC_flyuger_strips_0.md) — **«Флюгер», нулевой выпуск**: восемь одностраничных стрипов панель-за-панелью, deadpan-камертон вселенной. Каждый стрип — один канонический закон в форме шутки; прогнозы стрипов сверяются внутри выпуска.

[`COMIC_vtoraya_smeta_01.md`](COMIC_vtoraya_smeta_01.md) — **«Вторая смета» №1, «Дело о двухстах четырнадцати»**: полный сценарий выпуска на 20 страниц для художника (обложка, сплэши, бэкматтер, пост-титровая «строка Флюгера» с тизером №2). Пилотное дело ветки В в комикс-форме.

# predictor/ — координационная программа (циклы 1–3)

Переосмысление игры: игроки — **архитекторы**, которые могут договариваться; предиктор даёт **условный прогноз** исхода договорённости и **измеряет собственную уверенность**, а не декларирует её. Три прочтения — связывающие коалиции (002), точка Шеллинга (003), перформативность (004) — прогнаны тремя циклами.

## Движок: `spectral.py`

Извлечён (логика дословно) из отдельного проекта автора **SpectralPredictor v15** (Купман/DMD + остатки ResDMD по Колбруку):

- `change_op(Ztr, r)` — стабильный низкоранговый оператор изменения: `x(t+1) = x(t) + D·x(t)` (System B из v15 — победитель по точности и безопасности на 2696 датасетах);
- `blanket_diag(Ztr, r)` — спектральное разложение «одеяла Маркова»: доли порядка (μ_pp), границы (μ_sc), хаоса (μ_ac);
- `confidence(Ztr, r)` — доля μ_pp как **измеренная** предсказуемость: честная замена декларируемых «97,5%».

## Три свойства честного предиктора (измерены, не заявлены)

1. **Калибровка.** Публичный прогноз доли на горизонте H=30: MAE 0.023, 91% попаданий в ±0.05 (цикл 1, 003).
2. **Потолок самосбычи.** Перформативная цель сбывается только в достижимой зоне; за push≈0.15 реализация выходит на плато/спад (004).
3. **Наказание за переобещание.** Доверие к предиктору падает 1.0→0.0 при недостижимой цели — рычаг исчезает сам (004). «Всеобщего оракула» нет по построению.

## Главный результат программы

Единственное воспроизводимое достаточное условие роста честного индекса — **необратимое снижение издержки перехода** (002c: доля 0.61–0.71 устойчиво; цикл 3: E_hold на **5/5 новых сидах**). Шеллинг на инерционном прогнозе добавляет ровно ноль; перформативность и сетевое заражение — малые вторичные ускорители.

## Запуск

```bash
pip install -r ../requirements.txt
python3 exp_balance_002c.py     # эксперимент-прорыв, ~2–3 мин
python3 exp_balance_cycle3.py   # воспроизводимость + Шеллинг/перформативность, ~4–6 мин
```

Скрипты запускаются из этой директории (импортируют `spectral.py` локально) и пишут выходные файлы в текущую директорию; каноничные результаты — в `results/`.

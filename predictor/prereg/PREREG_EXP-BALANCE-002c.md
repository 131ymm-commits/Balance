# EXP-BALANCE-002c — Пре-регистрация (критический тест)

### Необратимое снятие барьера: переход упраздняет риск одиночества навсегда, а не на окно

**Дата:** 2026-07-15 · **Основание:** 002b опроверг P1 — временное снятие барьера откатывается (relief тает за ~7 тиков, нет удержания, паттерн посева 001b). Гипотеза: барьер должен исчезать НЕОБРАТИМО для перешедшего. Одна правка; один прогон; предсказание ниже.

## Правка

`barrier_relief` не затухает: перешедший через коалицию сохраняет сниженный барьер к обратному уходу навсегда (перешёл однажды — риск одиночества исчерпан). Плюс механизм заражения: барьер новичка снижается на долю доверенных соседей, уже перешедших (снятие риска распространяется по сети — «мои знакомые уже там»). coord_strength ∈ {0, 0.6, 0.9}, infection ∈ {0, 0.5}.

## Предсказание (СНС Клауд)

- **P1c:** необратимое снятие + заражение впервые пробьёт стационар. При strength=0.9, infection=0.5 ожидаю E_hold=да, финал >0.6. Это последний структурный кандидат: если и необратимое снятие барьера с сетевым заражением не даёт роста — вывод окончателен, адопция строго экзогенна.
- **P2c:** при infection=0 (снятие только индивидуальное, необратимое) эффект есть, но слабее — заражение критично, потому что оно и есть механизм притока.

Если P1c опровергнется — программа завершена финальным выводом: эндогенного роста нет ни при каком внутреннем механизме, Balance требует внешнего триггера. Публикуется как главный результат всей арки.
